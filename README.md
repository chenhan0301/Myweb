## My four-year learning journey

### Year 1 · 2022–2023 — Foundation
**Human Resources + Programming Foundations**

大一以科技應用與人力資源發展的基礎訓練為主，開始理解組織、人才與學習問題；同時接觸程式設計，並逐漸確立雙主修資訊工程的方向。

這個階段最重要的不是完成某一個 GitHub 專案，而是形成後來四年的核心問題：

> 能不能用資訊技術，更好地理解與支援人的決策？

### Year 2 · 2023–2024 — Build & Analyze
**Web Development + Python + Data**

我開始把程式做成真正可以被看見與使用的成果。

- [Web](https://github.com/chenhan0301/Web)  
  112-1 網際網路概論：GitHub Pages、Bootstrap、CSS、JavaScript、動態網頁與 Azure。

- [program-language](https://github.com/chenhan0301/program-language)  
  112-2 程式語言：Python、Pandas、資料結構、JSON / CSV、PTT 爬蟲、視覺化與文字處理。

**能力轉折：**  
從「把網頁做出來」進一步走向「把資料整理成可以回答問題的資訊」。

### Year 3 · 2024–2025 — System Thinking
**Database + Backend + Full System**

- [Database-System](https://github.com/chenhan0301/Database-System)

從 Flask + MySQL 開始，完成 CRUD、Search、Join、Blueprint，再延伸到 MongoDB。

Final Project 為 **Library Management System**，將 Books、Users、Loans 三類資料與前後端流程整合。

**能力轉折：**  
開始把前端、後端、資料與使用流程視為一個完整系統。

### Year 4 · 2025–2026 — Integration & Research
**AI + HR + Decision Support**

- [Report-template / LexiAI](https://github.com/chenhan0301/Report-template)
- [Live LexiAI report](https://chenhan0301.github.io/Report-template/)

畢業專題 LexiAI 將：
- 非同步面試
- Speech-to-Text
- LLM 分析
- JSON 結構化資料
- Web dashboard
- 人才適任性決策支援

整合成完整流程。

我主要負責：
1. Prompt / 評估邏輯
2. 網頁報表與 Dashboard

專題驗證結果也讓我看到 AI 分析與傳統參考評估之間的落差，因此我的研究興趣從「做出 AI 系統」進一步轉向：

> **AI 的建議如何被理解、驗證與信任？**

這也成為目前研究計畫「生成式 AI 面試回饋之證據可追溯性對面試表現之影響」的起點。
